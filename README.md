# Webtech

## Welches Problem löst unser Projekt?

*Reicht dein geld nicht bis Monatsende?

*Schwierigkeiten dein Buget einzuhalten?

*Du hast keine Ahnung was in deinem Kühlschrank ist?


### genau bei diesen Problemen sorgt ***** für abhilfe!
Durch eine Einkaufsliste, mit einer enschließenden einpflege in deine Digitale Vorratskammer, verlierst du weder den überblick was du einkaufen musst noch was du in deinem Vorrat hast.
Da du jeden Monat ein Buget festlegst, kannst du genau im Auge behalten wieviel Geld du noch hast.
